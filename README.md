# RuangAgenda

RuangAgenda adalah aplikasi web untuk mencatat dan memantau agenda kegiatan mahasiswa, mulai dari tugas kuliah, kegiatan organisasi, sampai agenda pribadi. Semua kegiatan tampil dalam satu halaman sehingga mudah dilihat dan diatur.

## Cara Memakai

**Menambah kegiatan**
Isi judul, kategori, tanggal, dan deskripsi pada form "Tambah Kegiatan", lalu klik tombol tambah. Judul dan tanggal wajib diisi. Kegiatan baru muncul paling atas.

**Melihat detail**
Klik "Lihat Detail" pada kartu kegiatan untuk membaca deskripsi, dan klik "Sembunyikan Detail" untuk menutupnya.

**Menandai selesai**
Klik "Tandai Selesai" saat kegiatan sudah dikerjakan. Judulnya akan dicoret. Klik "Tandai Belum" untuk mengembalikannya.

**Mencari kegiatan**
Ketik kata kunci di kolom pencarian. Daftar langsung menyesuaikan dengan judul dan deskripsi kegiatan.

**Memfilter kegiatan**
Pilih Semua, Belum, atau Selesai untuk menampilkan kegiatan sesuai statusnya. Filter dan pencarian bisa dipakai bersamaan.

**Menghapus kegiatan**
Klik "Hapus", lalu setujui konfirmasi yang muncul.

**Mengisi data diri**
Nama dan NIM dapat diisi atau diubah lewat tombol "Ubah Data Diri" di menu.

## Tampilan

Aplikasi dapat dipakai di HP, tablet, dan komputer. Di layar kecil, menu navigasi dibuka lewat tombol menu.

## Catatan

Data kegiatan yang ditambahkan disimpan sementara di halaman dan akan kembali ke contoh awal saat halaman dimuat ulang.
